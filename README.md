# Na Grzyby Site

Public landing, privacy and support pages for the Na Grzyby iOS app.

## GitHub Pages

Enable with:

Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.

Pages:
- `/` — landing page
- `/privacy.html` — bilingual Privacy Policy
- `/support.html` — bilingual Support page

Support contact: `nagrzyby.support@gmail.com`
